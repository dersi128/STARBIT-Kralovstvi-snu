# Zachované starší pokusy

Tato složka se neimportuje do Godotu a není součástí exportu hry.

- `prototypes/bit/`: původní zkušební hráč a dva pomocné skripty z kořene projektu.
  Aktivní Bit je nadále `scenes/Bit.tscn` + `scripts/player.gd`.
- `generators/`: starší jednorázové generátory, které přepisovaly mapy a assety.
  Jsou zachované jako historický zdroj; jejich relativní cesty odpovídají
  původnímu umístění. Nespouštěj je nad současnou hrou bez úpravy a kopie projektu.

Žádná z těchto scén není odkazovaná z aktuální kampaně. Přesun uchovává práci
k případnému obnovení, neoznačuje ji za dokončený ani podporovaný herní systém.
