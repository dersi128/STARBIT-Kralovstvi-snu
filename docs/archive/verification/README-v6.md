# Ověření v6
Godot 4.7.2 stable. Automatické kontroly v6: všechny prošly.
Automatický hráč dokončil všech pět levelů pohybem a skákáním včetně bosse a Fouka.
Kontrolovány animace, orientace nepřátel, sbírání hvězdy/krystalu, podmínka brány,
restart, přechod do menu a pokračování i kolize šablony s TileMapLayer.
Skutečné snímky hry byly vykresleny přes OpenGL; hvězda a krystal jsou po opravě viditelné.
Testy při ukončení hlásí několik neuvolněných instancí/zdrojů; funkční kontroly prošly.
Nejde o testování dětmi ani test všech možných vlastních map.
